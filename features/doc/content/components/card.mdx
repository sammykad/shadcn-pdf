## Features

- A bordered, rounded container for grouping PDF content.
- Shared spacing scale and theme tokens via the PDF provider.

<Callout type="info">
  `card` is a PDF component rendered with @react-pdf/renderer, not a DOM
  element. It is meant to live inside a `PDFDocument`/`PDFPage`.
</Callout>

## Usage

```tsx
import {
  PDFCard,
  PDFCardHeader,
  PDFCardTitle,
  PDFCardDescription,
  PDFCardAction,
} from "@/components/pdf/card";

<PDFCard>
  <PDFCardHeader>
    <PDFCardTitle>Monthly billing</PDFCardTitle>
    <PDFCardDescription>Pro plan · Renews 01 Sep 2026</PDFCardDescription>
    <PDFCardAction>Active</PDFCardAction>
  </PDFCardHeader>
</PDFCard>;
```

Every part of the card accepts a Tailwind-style `className` prop for
one-off tweaks — no raw `StyleSheet` needed:

```tsx
<PDFCard className="gap-3 rounded-lg border bg-muted/10 p-3">
  <PDFCardHeader>
    <PDFCardTitle className="text-base font-semibold">Monthly billing</PDFCardTitle>
    <PDFCardDescription className="text-muted-foreground">
      Pro plan · Renews 01 Sep 2026
    </PDFCardDescription>
  </PDFCardHeader>
  <PDFCardFooter className="justify-between">
    <span>Total due</span>
    <span>$29.00</span>
  </PDFCardFooter>
</PDFCard>;
```

## Examples

### Demo

Install the `card-demo` example to see the full structure — header with an
action, content, and footer — rendered in a document.

```bash
npx shadcn@latest add @shadcn-pdf/card-demo
```

### Default size

Use the default `size` for standard card spacing.

```tsx
<PDFCard>
  <PDFCardHeader>
    <PDFCardTitle>Monthly billing</PDFCardTitle>
    <PDFCardAction>Active</PDFCardAction>
  </PDFCardHeader>
  <PDFCardFooter>$29.00 due</PDFCardFooter>
</PDFCard>
```

### Compact size

Use `size="sm"` for denser layouts.

```tsx
<PDFCard size="sm">
  <PDFCardHeader>
    <PDFCardTitle>Compact card</PDFCardTitle>
  </PDFCardHeader>
</PDFCard>
```
