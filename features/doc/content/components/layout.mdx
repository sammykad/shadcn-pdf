## Overview

Layout is handled by `PDFContainer` from `@/components/pdf`. Use className props for flex direction, gap, and alignment.

```tsx
import { PDFDocument, PDFPage } from "@/components/pdf/document";
import { PDFContainer, PDFText } from "@/components/pdf";

export default function LayoutDemo() {
  return (
    <PDFDocument title="Layout Demo" author="shadcn-pdf">
      <PDFPage>
        {/* Column */}
        <PDFContainer className="flex-col gap-3">
          <PDFText>Item 1</PDFText>
          <PDFText>Item 2</PDFText>
        </PDFContainer>

        {/* Row */}
        <PDFContainer className="flex-row gap-2 justify-between">
          <PDFText>Left</PDFText>
          <PDFText>Right</PDFText>
        </PDFContainer>

        {/* Grid (flexWrap) */}
        <PDFContainer className="flex-row flex-wrap gap-3">
          <PDFContainer className="w-[30%]"><PDFText>Cell 1</PDFText></PDFContainer>
          <PDFContainer className="w-[30%]"><PDFText>Cell 2</PDFText></PDFContainer>
          <PDFContainer className="w-[30%]"><PDFText>Cell 3</PDFText></PDFContainer>
        </PDFContainer>
      </PDFPage>
    </PDFDocument>
  );
}
```

## Why no PDFStack / PDFRow / PDFGrid?

These were thin wrappers around `View`. Since `PDFContainer` is already simple, we removed the abstractions to keep things minimal — just like shadcn/ui does with HTML elements.

## Installation

No installation needed — `PDFContainer` is already part of `@/components/pdf`.

```bash
npm install @react-pdf/renderer
```
