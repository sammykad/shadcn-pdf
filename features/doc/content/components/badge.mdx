## Features

- Semantic color variants: `default`, `secondary`, `success`, `destructive`, `outline`, `ghost`, `link`.
- Zero-config — no provider needed, colors built in.
- Supports `className` prop for Tailwind-style overrides.

## Usage

```tsx
import { PDFBadge } from "@/components/pdf/badge";

<PDFBadge variant="success">Paid</PDFBadge>
<PDFBadge variant="destructive">Overdue</PDFBadge>
```

## With className

```tsx
<PDFBadge variant="success" className="px-3 py-1">
  Custom styled
</PDFBadge>
```
