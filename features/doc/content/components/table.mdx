## Features

- Layout primitives for tabular data in PDF documents.
- Header and body rows with consistent divider spacing.
- Shared typography and colors via the PDF provider.
- Cell-level alignment (`left` / `center` / `right`) and optional column widths, set via `className`.

<Callout type="info">
  `table` is a set of PDF components rendered with @react-pdf/renderer, not DOM
  elements. They are meant to live inside a `PDFDocument`/`PDFPage`.
</Callout>

## Examples

### Column widths

Set a column width via `className="w-[NN%]"` on a cell. Cells without a width share the remaining space equally.

```tsx
<PDFTable>
  <PDFTableHeader>
    <PDFTableRow>
      <PDFTableHead className="w-[60%]">Item</PDFTableHead>
      <PDFTableHead className="w-[20%] justify-end text-right">
        Qty
      </PDFTableHead>
      <PDFTableHead className="w-[20%] justify-end text-right">
        Total
      </PDFTableHead>
    </PDFTableRow>
  </PDFTableHeader>
</PDFTable>
```

### Last row without a divider

Set `className="border-b-0"` on the final `PDFTableRow` to remove its bottom border.

```tsx
<PDFTable>
  <PDFTableBody>
    <PDFTableRow>...</PDFTableRow>
    <PDFTableRow className="border-b-0">...</PDFTableRow>
  </PDFTableBody>
</PDFTable>
```
