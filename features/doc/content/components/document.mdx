## Features

- `PDFDocument` registers fonts and applies the theme automatically — use it instead of a raw `<Document>`.
- `PDFPage` applies the active font family, background, and default padding.
- `PDFHeader` / `PDFFooter` with an optional automatic page number.
- Accepts a partial theme override via the `theme` prop.
