## What is PDFFonts?

PDFFonts handles font registration for react-pdf. It registers the Geist Sans font family (multiple weights) and provides a safe fallback to Helvetica when font files aren't available.

This runs automatically when you use `PDFPage` — you don't need to call it manually. But if you want to customize fonts or check what's registered, the utility functions are available.

## How it works

1. **Auto-registration** — `PDFPage` calls `registerPDFFonts()` on first render.
2. **Safe fallback** — if Geist font files aren't found, Helvetica is used instead.
3. **Idempotent** — safe to call multiple times, skips already-registered families.
4. **Weight mapping** — font weights map to upright glyphs (no italic failures).

## Features

- Registers Geist Sans family with multiple weights.
- Falls back to Helvetica when no font files are present.
- Maps italic requests to upright glyphs to avoid render errors.
- Safe to call multiple times.
