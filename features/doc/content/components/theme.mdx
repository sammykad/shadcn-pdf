## Features

- A single source of truth for design tokens (colors, type scale, spacing, radius, fonts, page).
- `PDFProvider` + `usePDFTheme` let any PDF component read and override the theme.
- Deep-merges partial overrides, so you only customize what you need.

## Usage

Every PDF component in this library reads its tokens from the theme, so changing a value updates the whole document.

```tsx
import { PDFProvider } from "@/components/pdf/lib/provider";
import { PDFDocument, PDFPage } from "@/components/pdf/document";
import { Heading } from "@/components/pdf/typography";

<PDFDocument title="Custom" author="Acme">
  <PDFProvider value={{ colors: { primary: "#111827" } }}>
    <PDFPage>
      <Heading>Branded heading</Heading>
    </PDFPage>
  </PDFProvider>
</PDFDocument>
```
