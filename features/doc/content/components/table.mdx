## What is PDFTable?

PDFTable is a set of layout primitives for displaying tabular data in PDF documents — invoices, reports, receipts, or any structured data. Unlike HTML `<table>`, these components use flexbox under the hood since react-pdf doesn't support CSS tables.

Column widths are controlled via the `flex` prop (similar to CSS flexbox), giving you precise control over how space is distributed.

## When to use it

- **Invoices** — line items with quantity, price, and total columns.
- **Reports** — data tables with headers, rows, and summary footers.
- **Receipts** — itemized purchase lists.
- **Any data** that needs row/column structure.

## Features

- Flex-based column widths via `flex` prop — no percentage hacks.
- Auto-wraps strings in `<Text>`, React nodes pass through.
- Header, body, and footer sections with built-in borders.
- Full Tailwind support via `className`.

<Callout type="info">
  These are PDF components rendered with @react-pdf/renderer, not DOM elements.
  They live inside a `PDFDocument`/`PDFPage`.
</Callout>

## Column widths

Use the `flex` prop to control column proportions:

```tsx
<PDFTableHead flex={2}>Wide column</PDFTableHead>
<PDFTableHead flex={1}>Narrow column</PDFTableHead>
```
