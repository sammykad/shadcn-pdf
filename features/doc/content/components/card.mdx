## What is PDFCard?

PDFCard is a bordered, rounded container that groups related content — like invoices, billing summaries, or profile sections. It follows the same composable pattern as shadcn/ui's Card: a header, content area, footer, and optional action slot.

Each sub-component handles its own spacing and typography, so you just compose them together without worrying about layout details.

## When to use it

- **Invoices & receipts** — group line items, totals, and payment status.
- **Dashboards** — display metrics, summaries, or KPIs.
- **Forms** — wrap fieldsets with a title and description.
- **Any content** that benefits from a visual container with a border.

## Features

- Composable: `PDFCardHeader`, `PDFCardContent`, `PDFCardFooter`, `PDFCardAction`.
- Auto-layout: header auto-positions the action slot to the right.
- Zero-config — no provider needed.
- Full Tailwind support via `className`.

## Usage

```tsx
import { PDFDocument, PDFPage } from "@/components/pdf";
import { PDFCard, PDFCardHeader, PDFCardTitle, PDFCardDescription, PDFCardContent, PDFCardFooter } from "@/components/pdf/card";

function InvoiceCard() {
  return (
    <PDFDocument title="Invoice" author="Me">
      <PDFPage>
        <PDFCard className="rounded-lg border border-zinc-200">
          <PDFCardHeader className="p-4">
            <PDFCardTitle className="text-lg font-semibold">Invoice #001</PDFCardTitle>
            <PDFCardDescription className="text-sm text-zinc-400">Acme Corp</PDFCardDescription>
          </PDFCardHeader>
          <PDFCardContent className="px-4 pb-4">
            <PDFText className="text-sm">Content here</PDFText>
          </PDFCardContent>
          <PDFCardFooter className="px-4 pb-4">
            <PDFText className="text-sm font-bold">$1,200.00</PDFText>
          </PDFCardFooter>
        </PDFCard>
      </PDFPage>
    </PDFDocument>
  );
}
```
