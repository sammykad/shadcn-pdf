## What is PDFSection?

PDFSection provides two building blocks for structured content:

- **PDFSection** — a titled block with an optional description, wrapped in a bordered card (or plain mode). Perfect for grouping related fields under a heading.
- **PDFField** — a label-over-value pair for displaying key-value data like "Date: 3 April 2026" or "Total: $1,200".

Together they make it easy to build forms, detail views, and info grids without manually styling each label and value.

## When to use it

- **Invoices** — sections for "Billing Details", "Payment Terms", "Line Items".
- **Reports** — sections for "Student Info", "Grades", "Attendance".
- **Forms** — field groups with labels and values.
- **Any document** that needs organized, labeled content blocks.

## Features

- `PDFSection` — titled block with optional border, description, and card/plain modes.
- `PDFField` — label-over-value pair with flexible widths.
- Zero-config — no provider needed.
- Full Tailwind support via `className`.
