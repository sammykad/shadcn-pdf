## Features

- `PDFSection` — a titled block, optionally wrapped in a bordered card.
- `PDFField` — a label-over-value entry for info grids.
- Zero-config — no provider needed.
- Supports `className` prop for Tailwind-style overrides.

## Usage

```tsx
import { PDFDocument, PDFPage } from "@/components/pdf/document";
import { PDFSection, PDFField } from "@/components/pdf/section";
import { View } from "@react-pdf/renderer";
import { renderToBuffer } from "@react-pdf/renderer";

function MyDocument() {
  return (
    <PDFDocument title="My Document" author="Me">
      <PDFPage>
        <PDFSection title="Key Dates" description="Important term dates">
          <View style={{ flexDirection: "row" }}>
            <PDFField label="Results" value="3 April 2026" />
            <PDFField label="Next Term" value="10 June 2026" />
          </View>
        </PDFSection>
      </PDFPage>
    </PDFDocument>
  );
}

// Render to buffer
const buffer = await renderToBuffer(<MyDocument />);
```

## API reference

### PDFSection

| Prop | Type |
| --- | --- |
| title? | `ReactNode` |
| description? | `ReactNode` |
| children | `ReactNode` |
| as? | `"card" \| "plain"` |
| className? | `string` |
| style? | `Style` |

### PDFField

| Prop | Type |
| --- | --- |
| label | `ReactNode` |
| value | `ReactNode` |
| width? | `"1/2" \| "1/3" \| "1/4"` |
| className? | `string` |
| style? | `Style` |
