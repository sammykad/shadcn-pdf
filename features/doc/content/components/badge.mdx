## What is PDFBadge?

PDFBadge is a compact, pill-shaped label for displaying status or category tags in PDF documents. Think of it as the PDF equivalent of a HTML `<span>` with a background color — perfect for marking items as "Paid", "Pending", "Active", or "Overdue".

Each variant has a pre-defined color combination so you don't have to manually set background and text colors.

## When to use it

- **Invoice status** — Paid, Pending, Overdue, Cancelled.
- **Order tracking** — Shipped, Delivered, Processing.
- **Document labels** — Draft, Published, Archived.
- **Any short text** that needs visual emphasis without being a full heading.

## Features

- 7 semantic variants: `default`, `secondary`, `success`, `destructive`, `outline`, `ghost`, `link`.
- Pill-shaped with auto-sizing based on content.
- Zero-config — colors are built in.
- Full Tailwind support via `className`.
