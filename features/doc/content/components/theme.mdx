## What is PDFTheme?

PDFTheme is the design system backbone. It defines a single set of tokens — colors, typography scale, spacing, border radius, fonts, and page dimensions — that every component reads from.

Instead of passing `color="#333"` or `fontSize={12}` to every component, you set tokens once in the theme and everything inherits them. Override just what you need via `PDFProvider`.

## When to use it

- **Custom brand colors** — override `primary`, `accent`, `destructive` etc.
- **Different typography** — change the base font size or heading scale.
- **Consistent spacing** — adjust the spacing multiplier across all components.
- **Page defaults** — set default page size, padding, and background.

## Features

- Single source of truth for all design tokens.
- `PDFProvider` + `usePDFTheme` for reading and overriding.
- Deep-merges partial overrides — only customize what you need.
- Every component in the library reads from the theme automatically.
