## Features

- Layout primitives for tabular data in PDF documents.
- Header and body rows with consistent divider spacing.
- Shared typography and colors via the PDF provider.
- Cell-level alignment (`left` / `center` / `right`) and optional column widths.

<Callout type="info">
  `table` is a set of PDF components rendered with @react-pdf/renderer, not DOM
  elements. They are meant to live inside a `PDFDocument`/`PDFPage`.
</Callout>

## Usage

```tsx
import {
  Table,
  TableHeader,
  TableBody,
  TableRow,
  TableHead,
  TableCell,
} from "@/components/pdf/table";

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Item</TableHead>
      <TableHead align="right">Qty</TableHead>
      <TableHead align="right">Price</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow isLast>
      <TableCell>Widget</TableCell>
      <TableCell align="right">2</TableCell>
      <TableCell align="right">$19.00</TableCell>
    </TableRow>
  </TableBody>
</Table>;
```

## Examples

### Column widths

Use `width` on a cell to control its column width. Cells without a width share the remaining space equally.

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead width="60%">Item</TableHead>
      <TableHead align="right" width="20%">
        Qty
      </TableHead>
      <TableHead align="right" width="20%">
        Total
      </TableHead>
    </TableRow>
  </TableHeader>
</Table>
```

### Last row without a divider

Set `isLast` on the final `TableRow` to remove its bottom border.

```tsx
<Table>
  <TableBody>
    <TableRow>...</TableRow>
    <TableRow isLast>...</TableRow>
  </TableBody>
</Table>
```
