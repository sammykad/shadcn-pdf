## Overview

Layout is handled by `View` from `@react-pdf/renderer` directly. No wrapper components needed.

```tsx
import { PDFDocument, PDFPage } from "@/components/pdf/document";
import { View } from "@react-pdf/renderer";
import { PDFTextBlock } from "@/components/pdf/typography";

export default function LayoutDemo() {
  return (
    <PDFDocument title="Layout Demo" author="shadcn-pdf">
      <PDFPage>
        {/* Column */}
        <View style={{ flexDirection: "column", gap: 12 }}>
          <PDFTextBlock>Item 1</PDFTextBlock>
          <PDFTextBlock>Item 2</PDFTextBlock>
        </View>

        {/* Row */}
        <View style={{ flexDirection: "row", gap: 8, justifyContent: "space-between" }}>
          <PDFTextBlock>Left</PDFTextBlock>
          <PDFTextBlock>Right</PDFTextBlock>
        </View>

        {/* Grid (flexWrap) */}
        <View style={{ flexDirection: "row", flexWrap: "wrap", gap: 12 }}>
          <View style={{ width: "30%" }}><PDFTextBlock>Cell 1</PDFTextBlock></View>
          <View style={{ width: "30%" }}><PDFTextBlock>Cell 2</PDFTextBlock></View>
          <View style={{ width: "30%" }}><PDFTextBlock>Cell 3</PDFTextBlock></View>
        </View>
      </PDFPage>
    </PDFDocument>
  );
}
```

## Why no PDFStack / PDFRow / PDFGrid?

These were thin wrappers around `View`. Since react-pdf's `View` is already simple, we removed the abstractions to keep things minimal — just like shadcn/ui does with HTML elements.

## Installation

No installation needed — `View` is already part of `@react-pdf/renderer`.

```bash
npm install @react-pdf/renderer
```
