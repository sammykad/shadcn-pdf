## Features

- Semantic color variants: `default`, `secondary`, `success`, `destructive`, `outline`, `ghost`, `link`.
- Colors pulled from the shared PDF theme.
- Reusable style factory via `badgeVariants` and a `badge-demo` example.

## Examples

### Demo

Install the `badge-demo` example to see every variant rendered in a document.

```bash
npx shadcn@latest add @shadcn-pdf/badge-demo
```

### Semantic variants

Use `variant` to pick a color treatment.

```tsx
<PDFBadge variant="success">Paid</PDFBadge>
<PDFBadge variant="destructive">Overdue</PDFBadge>
<PDFBadge variant="outline">Outline</PDFBadge>
```

### With style overrides

Pass `style` to tweak sizing and layout.

```tsx
<PDFBadge style={{ paddingHorizontal: 12, height: 24 }}>Custom</PDFBadge>
```

### Reuse badge styles

`badgeVariants` returns the styles for a variant, so you can apply badge
styling to any `View`/`Text`.

```tsx
import { View, Text } from "@react-pdf/renderer";
import { usePDFTheme } from "@/components/pdf/lib/provider";
import { badgeVariants } from "@/components/pdf/badge";

function CustomBadge() {
  const theme = usePDFTheme();
  const styles = badgeVariants("success", theme);

  return (
    <View style={styles.root}>
      <Text style={styles.text}>Custom success</Text>
    </View>
  );
}
```
