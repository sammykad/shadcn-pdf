## Features

- Single component for all text: headings, body, captions, labels.
- Variants powered by `class-variance-authority` — easy to extend.
- `className` prop for full Tailwind control.
- `color` and `align` convenience props.

## Usage

### Headings

```tsx
import { PDFText } from "@/components/pdf";

<PDFText variant="h1">Page Title</PDFText>
<PDFText variant="h2">Section Heading</PDFText>
<PDFText variant="h3">Subsection</PDFText>
<PDFText variant="h4">Small Label</PDFText>
```

### Body & Utility

```tsx
<PDFText>Default body text</PDFText>
<PDFText variant="small" color="#71717a">Caption or helper text</PDFText>
<PDFText variant="muted">De-emphasized content</PDFText>
<PDFText variant="lead">Featured paragraph</PDFText>
<PDFText variant="large">Large display text</PDFText>
```

### With Tailwind className

```tsx
<PDFText variant="h1" className="text-3xl font-bold text-zinc-900">
  Custom title
</PDFText>

<PDFText variant="small" className="text-zinc-400 tracking-wide uppercase">
  Overline label
</PDFText>
```

### Alignment

```tsx
<PDFText align="center">Centered text</PDFText>
<PDFText align="right">Right-aligned text</PDFText>
```

## API reference

| Prop | Type | Default |
| --- | --- | --- |
| children | `ReactNode` | — |
| variant? | `"h1" \| "h2" \| "h3" \| "h4" \| "default" \| "muted" \| "lead" \| "small" \| "large"` | `"default"` |
| color? | `string` | theme foreground |
| align? | `"left" \| "center" \| "right"` | `"left"` |
| className? | `string` | — |
| style? | `Style` | — |
