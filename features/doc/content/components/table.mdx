## Features

- Layout primitives for tabular data in PDF documents.
- Column widths via `flex` prop — no percentage hacks.
- Strings auto-wrap in `<Text>`, React nodes pass through.
- Supports `className` prop for Tailwind-style overrides.

<Callout type="info">
  `table` is a set of PDF components rendered with @react-pdf/renderer, not DOM
  elements. They are meant to live inside a `PDFDocument`/`PDFPage`.
</Callout>

## Usage

```tsx
import {
  PDFTable,
  PDFTableHeader,
  PDFTableBody,
  PDFTableRow,
  PDFTableHead,
  PDFTableCell,
  PDFTableFooter,
} from "@/components/pdf/table";

<PDFTable>
  <PDFTableHeader>
    <PDFTableHead flex={2}>Invoice</PDFTableHead>
    <PDFTableHead flex={3}>Client</PDFTableHead>
    <PDFTableHead flex={2}>Amount</PDFTableHead>
  </PDFTableHeader>
  <PDFTableBody>
    <PDFTableRow>
      <PDFTableCell flex={2}>INV-001</PDFTableCell>
      <PDFTableCell flex={3}>Acme Corp</PDFTableCell>
      <PDFTableCell flex={2}>$1,200</PDFTableCell>
    </PDFTableRow>
  </PDFTableBody>
  <PDFTableFooter>
    <PDFTableCell flex={5}>Total</PDFTableCell>
    <PDFTableCell flex={2} style={{ fontWeight: 700 }}>$1,200</PDFTableCell>
  </PDFTableFooter>
</PDFTable>
```

## Column widths

Use `flex` prop to control column widths:

```tsx
<PDFTableHead flex={2}>Wide column</PDFTableHead>
<PDFTableHead flex={1}>Narrow column</PDFTableHead>
```
