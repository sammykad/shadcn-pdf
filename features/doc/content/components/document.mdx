## What is PDFDocument?

PDFDocument is the root wrapper for every PDF you generate. It handles three things you'd otherwise have to set up manually:

1. **Font registration** — automatically registers Geist Sans (with Helvetica fallback) so text renders correctly.
2. **Page structure** — `PDFPage` applies the active font, background color, and default padding.
3. **Header & footer** — `PDFHeader` and `PDFFooter` with optional automatic page numbering.

Think of it as the "document shell" — everything else (cards, tables, badges) goes inside.

## When to use it

Every PDF needs this. It's the starting point for invoices, reports, receipts, or any multi-page document.

## Features

- `PDFDocument` registers Geist fonts automatically — use it instead of a raw `<Document>`.
- `PDFPage` applies font family, background, and padding from the theme.
- `PDFHeader` / `PDFFooter` with optional page numbers.
- Supports `size` and `orientation` props for A4, Letter, A3, or custom dimensions.
- Zero-config — no provider or theme setup needed.

## Usage

```tsx
import { PDFDocument, PDFPage, PDFHeader, PDFFooter, PDFContainer, PDFText } from "@/components/pdf";

function MyDocument() {
  return (
    <PDFDocument title="My Document" author="Me">
      <PDFPage>
        <PDFHeader>
          <PDFContainer className="flex-col gap-1">
            <PDFText variant="h2" className="font-bold text-lg">Header</PDFText>
            <PDFText variant="small" color="#737373" className="text-xs">Subtitle</PDFText>
          </PDFContainer>
        </PDFHeader>
        <PDFContainer className="p-4">
          <PDFText className="text-sm text-foreground">Body content here.</PDFText>
        </PDFContainer>
        <PDFFooter page={1} right="shadcn-pdf" />
      </PDFPage>
    </PDFDocument>
  );
}
```

## API reference

### PDFPage

| Prop | Type |
| --- | --- |
| children | `ReactNode` |
| size? | `"A4" \| "LETTER" \| "A3" \| [number, number]` |
| orientation? | `"portrait" \| "landscape"` |
| className? | `string` |
| style? | `Style` |

### PDFHeader

| Prop | Type |
| --- | --- |
| children | `ReactNode` |
| bordered? | `boolean` |
| className? | `string` |
| style? | `Style` |

### PDFFooter

| Prop | Type |
| --- | --- |
| left? | `ReactNode` |
| right? | `ReactNode` |
| pageNumber? | `boolean` |
| page? | `number` |
| className? | `string` |
| style? | `Style` |
