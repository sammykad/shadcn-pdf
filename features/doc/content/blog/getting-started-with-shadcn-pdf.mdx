shadcn-pdf is a modern library for generating PDFs using React components styled with shadcn/ui. It lets you compose PDFs the same way you build UIs — with components, props, and TypeScript.

## Why shadcn-pdf?

Traditional PDF generation often means wrestling with:
- Low-level coordinate-based APIs
- Limited styling options
- No component reusability
- Poor TypeScript support

shadcn-pdf solves this by letting you use **React components** you already know.

## Quick Start

```bash
npx shadcn-pdf@latest init
```

This sets up a Next.js project with PDF generation ready to go.

## Your First PDF

Create a document using familiar components:

```tsx
import { Document, Page, Text, View } from "@shadcn/pdf"
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"

export function Invoice() {
  return (
    <Document>
      <Page size="A4" style={{ padding: 48 }}>
        <View style={{ gap: 24 }}>
          <Text as="h1" style={{ fontSize: 32, fontWeight: "bold" }}>
            Invoice #INV-2026-001
          </Text>

          <Card>
            <CardHeader>
              <CardTitle>Billing Details</CardTitle>
            </CardHeader>
            <CardContent>
              <Text>Acme Corporation</Text>
              <Text>123 Business Ave, Suite 100</Text>
              <Text>San Francisco, CA 94105</Text>
            </CardContent>
          </Card>
        </View>
      </Page>
    </Document>
  )
}
```

## Styling with Tailwind

Since shadcn-pdf uses Yoga layout engine, you can use Tailwind-like utilities:

```tsx

  </Text>

  </Text>
</View>
```

## Frequently Asked Questions

### What is shadcn-pdf?
shadcn-pdf is a component library for generating PDFs in React using @react-pdf/renderer. It follows the shadcn/ui registry pattern — you install components with the CLI and own the code. No runtime black box.

### How is shadcn-pdf different from react-pdf?
shadcn-pdf builds on @react-pdf/renderer and adds a component layer: reusable styled components, a theme system, Tailwind-style utilities, and a registry pattern. You get a better developer experience while still using react-pdf under the hood.

### What styling system does shadcn-pdf use?
shadcn-pdf includes a tw() utility that resolves Tailwind CSS class names — including the full Tailwind v4 color palette — into react-pdf styles at render time. No global CSS file is needed.
