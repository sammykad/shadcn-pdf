## Features

- Registers the Geist Sans family (multiple static weights) with @react-pdf/renderer.
- Safe to call multiple times; skips families without available font files.
- Falls back to Helvetica when no font files are present, so rendering never throws.
- Maps italic requests to upright glyphs to avoid hard failures.

## Usage

Register the font once, then use `useFontFamily` to pick the active family.

```tsx
import { registerPDFFonts, useFontFamily } from "@/components/pdf/core/fonts";

const family = registerPDFFonts();
// -> "Geist Sans" when fonts exist, otherwise the fallback family.
```
