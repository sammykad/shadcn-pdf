## What is PDFDivider?

PDFDivider is a simple horizontal line that visually separates content sections. It's a 1px tall `View` that spans the full width of its container, using the theme's border color by default.

Use it to break up long documents into digestible sections — between invoice line items, between form fields, or between header and body content.

## When to use it

- **Invoices** — separate line items from the total section.
- **Reports** — divide sections or chapters.
- **Forms** — separate field groups.
- **Any document** that needs visual breathing room between sections.

## Features

- Full-width by default, uses theme border color.
- Minimal — just a 1px line, no extra spacing logic.
- Full Tailwind support via `className`.
